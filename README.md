# Gender Watchdog — Evidence Repository

Primary evidence archive supporting the [genderwatchdog.org](https://genderwatchdog.org) advocacy campaign documenting academic fraud, sexual violence cover-ups, and falsified international partnerships at Dongguk University (Seoul, South Korea).

## About This Repository

This repository stores primary-source evidence collected in the course of investigating:

- **Falsified international university partnerships** — FOI responses from UBC, University of Southampton, and others confirming no active partnership exists despite Dongguk's claims
- **Sexual violence cover-ups** — Institutional negligence, delayed disciplinary action, and disbanding of the Women's Student Council during Korea's MeToo movement (2018)
- **Title IX compliance risks** — Risk exposure for US/Canadian universities maintaining partnerships with Dongguk's film program (risk score: 81/100 per KWDI data analysis)
- **IEQAS certification fraud** — Evidence submitted to seven Korean government oversight bodies documenting the gap between certified status and campus safety reality
- **Targeting of international students** — Documented testimonies (Xiaohongshu/小红书) showing racialized sexual violence against foreign female students

Endorsed by [End Rape On Campus (EROC)](https://endrapeoncampus.org/).

## Repository Structure

```
evidence-repo/
├── imgs/               # Screenshots and image evidence
│   └── scrubs-YYYYMMDD/
│       └── <institution>/   # Organized by institution name/abbreviation
├── email-eml/          # Email correspondence evidence (.eml files)
├── wacz/               # Web archive files (.wacz) — full page captures
├── audio/              # Audio evidence
└── videos/             # Video evidence
```

### Naming Conventions

| Directory | Contents | Notes |
|-----------|----------|-------|
| `imgs/scrubs-YYYYMMDD/` | Screenshot scrubs by date | Date = scrape/capture date (YYYYMMDD) |
| `email-eml/` | Raw email files | Preserves headers and metadata |
| `wacz/` | [WACZ](https://specs.webrecorder.net/wacz/1.1.1/) web archives | Replayable via [Webrecorder](https://webrecorder.net/) |
| `audio/` | Audio recordings | Interviews, hearings, etc. |
| `videos/` | Video evidence | Screen recordings, news clips, etc. |
